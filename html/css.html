Primeiros passos com CSS

Aprenda a conectar folhas de estilo ao seu HTML e transformar a aparência das suas páginas.

O que é CSS?

O CSS (Cascading Style Sheets) é a linguagem usada para estilizar elementos HTML. Enquanto o HTML cuida da estrutura, o CSS define cores, fontes, espaçamentos, tamanhos e o posicionamento de cada bloco na tela.

Uma regra CSS é composta por um seletor (quem você quer estilizar), uma propriedade (o que mudar) e um valor (como deve ficar).

Como implementar na prática

  1. Na mesma pasta do seu index.html, crie um arquivo chamado style.css.
  2. Dentro da tag <head> do seu HTML, conecte o arquivo usando a tag <link>:
<head>
    <meta charset="UTF-8">
    <title>Minha Página Estilizada</title>
    <link rel="stylesheet" href="style.css">
</head>

Agora, adicione suas primeiras regras dentro do arquivo style.css:

body {
    background-color: #f8fafc;
    font-family: Arial, sans-serif;
    padding: 32px;
}

h1 {
    color: #2563eb;
    font-size: 36px;
}

p {
    color: #475569;
    line-height: 1.6;
}
Para praticar: Crie uma classe no HTML (ex: <p class="destaque">) e estilize apenas ela no CSS usando o ponto na frente: .destaque { font-weight: bold; }.
