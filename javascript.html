Primeiros passos com JavaScript

Adicione lógica, interatividade e reaja às ações do usuário diretamente no navegador.

O que é JavaScript?

O JavaScript (JS) é a linguagem de programação da web. Com ele, sua página deixa de ser estática e passa a responder a cliques, validar formulários, alterar textos dinamicamente e buscar dados de servidores.

Como implementar na prática

  1. Crie um arquivo chamado script.js na mesma pasta do seu projeto.
  2. Conecte o script no final do <body> do seu HTML (antes de fechar a tag) para garantir que os elementos da página já tenham carregado:
<body>
    <h1 id="titulo">Olá!</h1>
    <button id="botao">Clique aqui</button>

    <script src="script.js"></script>
</body>

No arquivo script.js, capture o botão e faça o texto mudar ao clicar:

const titulo = document.getElementById("titulo");
const botao = document.getElementById("botao");

botao.addEventListener("click", function () {
    titulo.textContent = "Você ativou o JavaScript!";
});
Para praticar: Tente adicionar um contador de cliques usando uma variável let cliques = 0; e incremente com cliques++ toda vez que o botão for pressionado.
