Primeiros passos com C

Conheça a linguagem que moldou os sistemas operacionais e aprenda a compilar seu primeiro programa.

O que é a linguagem C?

O C é uma linguagem compilada de propósito geral, famosa pela velocidade e controle direto sobre o hardware e a memória. Aprender C dá uma base excelente para entender como qualquer outra linguagem funciona por baixo dos panos.

Como implementar na prática

  1. Instale um compilador C, como o GCC (no Windows via MinGW, ou nativamente no Linux/macOS).
  2. Crie um arquivo chamado main.c e adicione o código abaixo:
#include <stdio.h>

int main() {
    printf("Olá, mundo em C!\n");
    return 0;
}

No terminal, compile e execute o programa com os comandos:

gcc main.c -o programa
./programa
Para praticar: Crie duas variáveis inteiras (int a = 5, b = 3;) e exiba a soma delas usando printf("Soma: %d\n", a + b);.

Teste seus conhecimentos

Responda às perguntas abaixo para fixar o conteúdo de C.

1. Qual biblioteca precisamos incluir no início do arquivo para usar a função printf()?

2. Qual função é usada para exibir uma mensagem no terminal em C?
