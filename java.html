Primeiros passos com Java

Entenda a estrutura orientada a objetos do Java e rode sua primeira classe na JVM.

O que é Java?

O Java é uma linguagem orientada a objetos, fortemente tipada e multiplataforma. Seu código roda dentro da JVM (Java Virtual Machine), permitindo que o mesmo programa funcione em Windows, Linux ou macOS sem precisar ser reescrito.

Como implementar na prática

  1. Instale o JDK (Java Development Kit) no seu computador.
  2. Crie um arquivo chamado Main.java (o nome do arquivo deve ser exatamente igual ao nome da classe pública):
public class Main {
    public static void main(String[] args) {
        String linguagem = "Java";
        System.out.println("Olá, mundo com " + linguagem + "!");
    }
}

No terminal, compile o código com javac e execute com java:

javac Main.java
java Main
Para praticar: Crie um método simples chamado saudar(String nome) dentro da classe Main e chame-o a partir do main.
