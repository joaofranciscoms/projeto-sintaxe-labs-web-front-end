Primeiros passos com C++

Descubra como o C++ expande o C com recursos modernos e Programação Orientada a Objetos.

O que é C++?

O C++ nasceu como uma extensão da linguagem C, adicionando suporte a classes, objetos, bibliotecas padronizadas (STL) e abstrações mais seguras, sem abrir mão do alto desempenho.

Como implementar na prática

  1. Com o compilador G++ instalado, crie um arquivo chamado main.cpp.
  2. Escreva o exemplo abaixo utilizando a biblioteca <iostream> para entrada e saída de dados:
#include <iostream>

int main() {
    std::string nome = "Sintaxe Labs";
    std::cout << "Bem-vindo ao " << nome << "!" << std::endl;
    return 0;
}

No terminal, compile e execute com:

g++ main.cpp -o programa
./programa
Para praticar: Use std::cin >> nome; para pedir que o usuário digite o próprio nome no terminal antes de exibir a mensagem de boas-vindas.
