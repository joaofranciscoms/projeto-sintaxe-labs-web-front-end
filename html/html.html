Primeiros passos com HTML

Entenda o que é a linguagem de marcação da web e como criar sua primeira página do zero.

O que é HTML?

O HTML (HyperText Markup Language) não é uma linguagem de programação, mas sim uma linguagem de marcação. Ele é responsável por definir a estrutura e o significado de todo o conteúdo de uma página: títulos, parágrafos, imagens, links e botões.

Ele funciona através de tags (elementos entre sinais de menor e maior, como <p>), que geralmente possuem uma abertura e um fechamento.

Como implementar na prática

  1. Crie uma pasta no seu computador para o projeto.
  2. Abra o seu editor de código (como o VS Code) e crie um arquivo chamado index.html.
  3. Escreva a estrutura básica abaixo, salve e abra o arquivo dando dois cliques nele para ver no navegador.
<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
</head>
<body>
    <h1>Olá, mundo!</h1>
    <p>Este é o meu primeiro parágrafo em HTML.</p>
    <a href="https://github.com">Acessar o GitHub</a>
</body>
</html>
Para praticar: Tente adicionar um subtítulo usando a tag <h2> e uma lista de itens usando <ul> e <li> dentro do <body>.
