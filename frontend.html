Trilha Front-end

Principais tecnologias

Siga a ordem abaixo para construir sua base no desenvolvimento de interfaces web.

  1. Passo 1 • Estrutura

    HTML

    A base de qualquer página web. Aprenda a estruturar textos, imagens, links, formulários e usar tags semânticas corretamente.

    Começar HTML
  2. Passo 2 • Estilização

    CSS

    Dê vida e estilo às páginas. Estude cores, tipografia, Flexbox, Grid e design responsivo para adaptar seu site a qualquer tela.

    Começar CSS
  3. Passo 3 • Interatividade

    JavaScript

    Adicione lógica e comportamento ao navegador. Aprenda variáveis, funções, eventos e manipulação do DOM para criar páginas dinâmicas.

    Começar JavaScript
